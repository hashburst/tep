# Protocol freeze status

Status: NON-NORMATIVE / PRE-FREEZE

No TEP wire schema, ledger record, PoH construction, consensus rule, address-resolution rule, federation rule or sovereignty object is frozen by this repository initialization.

Freeze prerequisites:

1. extract the relevant mechanisms from the authoritative patent text;
2. inventory the deployed HB-TEP implementation currently present in node-installer;
3. identify matches, extensions and divergences;
4. define TEP Ledger and proprietary TEP-PoH without analogy-driven substitutions;
5. define addressing/name resolution and transport boundaries;
6. create machine-readable schemas and conformance vectors;
7. review compatibility with existing deployed nodes;
8. only then mark TEP protocol v1 as frozen.
